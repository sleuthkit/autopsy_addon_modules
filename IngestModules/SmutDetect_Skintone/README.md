- __Description:__ Simple Scan of JPG, BMP, PNG & GIF files (selection of files based on file signatures) for pixels with skin tone and computing percentages. Files are tagged with skin-tone percentages in increments of 10. It also tags images if nudity is detected an image, using the Rigan Ap-apaid Algorithm to allow a categorised view of thumbnails.
